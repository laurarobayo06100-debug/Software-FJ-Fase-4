# Software FJ — Fase 4

Proyecto de Laura Dayana Robayo Mahecha para el curso de Programación de la UNAD.

El programa registra clientes y gestiona reservas de salas, alquileres de equipos y asesorías. Cuando una operación falla, guarda el error y continúa con la siguiente.

## Cómo ejecutar el programa

1. Descarga el archivo Software_FJ.ipynb y ábrelo en Google Colab.
2. Selecciona «Entorno de ejecución» y luego «Ejecutar todas».
3. Revisa la última línea del cuaderno. Debe mostrar «20/20 resultados esperados».

## Resultados de las pruebas

Se ejecutaron 20 operaciones. El programa aceptó 11 y rechazó 9 por errores previstos. Por ejemplo, al intentar reservar una sala ocupada, registró el error. Después de cancelar la primera reserva, permitió reservar la sala de nuevo.

El archivo software_fj.log contiene el registro de las 20 operaciones.
